# Job Portal with Employer Dashboard

## 60-Day Capstone Project

### Domain

Recruitment / Human Resource Management

## Project Overview

The Job Portal with Employer Dashboard is a web-based application that helps employers manage job postings and candidate applications efficiently.

## Objectives

- Allow employers to create and manage job postings
- Allow employers to view job applications
- Help employers search and manage candidates
- Provide an easy-to-use employer dashboard

## Key Features

- Employer registration and login
- Employer dashboard
- Job posting management
- Candidate application management
- Candidate search and filtering
- Application status tracking
- Employer profile management
- Responsive user interface

## Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js / Express
- Database: MongoDB / MySQL
- Version Control: Git and GitHub

1. Clone the repository.
2. Install dependencies using npm install.
3. Configure environment variables.
4. Start the application using npm start.

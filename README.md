# Job Portal with Employer Dashboard

## 60-Day Capstone Project

### Domain

Recruitment / Human Resource Management

### Objective

Build a web application where employers can post and manage job vacancies, job seekers can search and apply for jobs, and administrators can manage users, job listings, and recruitment activities efficiently.

### Technology Stack

* Frontend: HTML, CSS, JavaScript
* Backend: Spring Boot (Java)
* Database: MySQL

### Project Status

Project planning completed.
